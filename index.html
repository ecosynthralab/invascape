INVASCAPE

A field-to-decision pipeline for invasive alien plant species management: one Plot ID, one GPS capture, three connected tools — from data collection through to priority tiers and remediation guidance.

Step 1 · Data Collection
PhytoScout
Plot ID, GPS, zone/role, and species/quadrat survey with DAFOR abundance and live diversity indices. Open to field workers and the general public.
Step 2 · Condition Assessment
Habitat Scorer
11-criterion habitat condition scoring tied to the same Plot ID, with live mean score and pristine/degraded classification.
Step 3 · Decision Support
Decision Layer
Joins habitat condition, infestation density, and GEE spatial predictors into a priority tier per plot, with species-specific remediation guidance grounded in Nigeria-focused literature.
How data flows
1 Capture a plot in PhytoScout — Plot ID and GPS are set once.
2 Score the same plot's condition in Habitat Scorer, using the same Plot ID.
3 Open the Decision Layer to see both joined automatically, plus optionally import GEE predictor values, and get a priority tier + remediation note per plot.
